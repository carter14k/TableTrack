TableTrack

TableTrack is a simple restaurant order management system that helps users record, view, search, and manage customer orders.

Features

- Add new restaurant orders.
- Record table number, dish name, category, quantity, unit price, and order date.
- Automatically calculate the total price of each order.
- View all recorded orders in a table.
- Search orders by dish name or table number.
- Filter orders by category.
- Delete orders.
- Save order data using browser Local Storage.

Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Use the navigation links to access the dashboard, add orders, and view orders.

Data Storage

TableTrack uses the browser's Local Storage to save order information. Orders remain saved in the same browser unless the stored data is cleared.
